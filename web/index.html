01 · About

One brain, two chains, one minute at a time

fly-trader does not use a neural network shaped like a brain. It uses the brain: the synapse-level wiring diagram of an adult fruit fly, run on its real, signed connections, with a mushroom body that keeps learning from what every trade earns.

The brain

The wiring comes from FlyWire FAFB v783, the first complete synaptic connectome of an adult animal brain. Every neuron is present. Every connection between them is a real, electron-microscopy-reconstructed synapse.

How it works

Sensing. Once a minute, every graduated memecoin on Solana and Robinhood Chain becomes one row of 68 inputs: returns, order flow, volume, liquidity, age, the token's launch, its creator's record and what winning wallets are doing in it. The row enters the fly through its sensory neurons, the ones that in a living fly carry smell, taste, touch and temperature.

The teacher. A gradient-boosted selector predicts each row's return after every fee and the price impact. It is trained on both chains' history and goes to work only after beating random picks on weeks it never saw.

The fly. Activity flows through the connectome only where the wiring allows. The fly starts as its teacher and buys what the teacher buys; its mushroom body then learns, trade by trade, where the teacher is wrong.

Learning. When a trade closes, dopamine-gated plasticity at the Kenyon cell → MBON synapses, the site of associative learning in a real fly, learns what it made.

Acting. Each buy is sized by how certain the model is and sold when its hold ends.

What we taught the fly

UNIVERSE

Graduated memecoins, two chains

  • Solana: pump.fun graduates on PumpSwap
  • Robinhood Chain: Pons graduates on Uniswap v4
  • Only tokens with real liquidity and recent volume
STRATEGIES

Fitted, not hand-picked

  • Each strategy has its own model, buy line and hold
  • A win filter and a dump veto screen every pick
THE GATE

Nothing trades unproven

  • Settings are chosen on one stretch of history and judged on a later one
  • A model must make money after costs and beat random picks
  • The fly must pass a replay on each chain before it trades
LEARNING

What the fly may change

  • Only its Kenyon cell → MBON synapses, by dopamine-gated plasticity
  • Its learning can veto a buy, never add one
SIZING

Bet what the record supports

  • A quarter of the Kelly bet for each pick's score
  • Capped by the bankroll and the pool's depth
RISK RAILS

Capital protection outside the brain

  • Kill switch on drawdown, circuit breaker on failed transactions
  • Every swap is simulated and capped before it is signed

Install with Docker: trade with the shipped fly

  1. Download the release and add your keys

    git clone -b distribution https://github.com/bryceweiner/fly-trader.git && cd fly-trader
cp .env.example .env    # paste HELIUS_API_KEY and JUPITER_API_KEY

  2. Start it

    docker compose up -d --build
# NVIDIA:  docker compose -f docker-compose.yml -f docker-compose.cuda.yml up -d --build
# AMD:     docker compose -f docker-compose.yml -f docker-compose.rocm.yml up -d --build

  3. Create and fund the wallet

    Back up .env: it holds the only copy of the wallet's key. Send the wallet 0.5 SOL, then restart.

    docker compose exec fly fly-trader wallet new
docker compose restart fly

  4. Watch it

    Open http://localhost:8501. It trades paper until 20 trades have closed, then the wallet.

Install from source: train your own

  1. Clone and install

    git clone https://github.com/bryceweiner/fly-trader.git && cd fly-trader
uv sync                  # macOS: Metal
uv sync --extra cu126    # Linux, one of: cpu · cu126 · cu130 (NVIDIA) · rocm72 (AMD)

  2. Configure and create the database

    Paste your keys into .env.

    cp .env.example .env
createdb fly_trader
uv run fly-trader init-db

  3. Build the brain

    mkdir -p data/brain/raw && cd data/brain/raw
F=https://raw.githubusercontent.com/snedea/flybrain/main/data
curl -LO $F/connections.csv.gz -LO $F/neurons.csv.gz -LO $F/classification.csv.gz
curl -LO https://raw.githubusercontent.com/flyconnectome/flywire_annotations/main/supplemental_files/Supplemental_file1_neuron_annotations.tsv
cd - && uv run fly-trader build-connectome

  4. Open the console

    Starts every worker and serves the dashboard on http://localhost:8501.

    uv run fly-trader ui

  5. Train

    uv run fly-trader train-selector
uv run fly-trader train-fly-selector
uv run fly-trader fly-replay

  6. Go live

    Fund the bot wallet, run the smoke test, then set LIVE_ENABLED=1 (RH_LIVE_ENABLED=1 for Robinhood Chain).

    uv run fly-trader wallet new
uv run fly-trader swap-smoke --sol 0.01
uv run fly-trader rh-smoke --yes
